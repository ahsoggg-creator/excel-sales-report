# excel-sales-report

Сводит отчеты по продажам от нескольких филиалов в один Excel-файл: чистит данные, убирает дубли и строит сводную по месяцам с графиком. То, что руками занимает полдня и копипаст из 4 файлов, делается одной командой.

Скрипт рассчитан на реальные "кривые" файлы: шапка отчета над таблицей, разные названия колонок в разных филиалах (Количество / Кол-во / Кол-во, шт), даты то датой, то текстом, цены вида "54 990 р.", лишние пробелы, пустые строки и "Итого" внизу.

На выходе `report.xlsx`:
- лист "Сводная" - выручка по филиалам и месяцам, итоги, столбчатая диаграмма
- лист "Данные" - все строки одной чистой таблицей, с фильтром по любой колонке

## Запуск

```
pip install -r requirements.txt
python merge_reports.py
```

Отчеты берутся из папки `input`, филиал определяется по имени файла. Можно указать свои пути:

```
python merge_reports.py --input D:\отчеты\март --output март.xlsx
```

В папке `input` лежат тестовые отчеты, пересоздать их можно через `python make_sample_data.py`.

Если у вас колонки называются по-другому - добавьте варианты в словарь `COLUMNS` в начале `merge_reports.py`, форматы дат там же в `DATE_FORMATS`.
