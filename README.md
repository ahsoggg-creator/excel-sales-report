# Сводный отчет по продажам из нескольких Excel-файлов

Скрипт берет отчеты филиалов (каждый в своем .xlsx), приводит их к одному виду и собирает в один файл со сводной таблицей и графиком.

Типичная ситуация: каждый филиал присылает свой файл, где-то заголовок не в первой строке, колонки называются по-разному ("Количество", "Кол-во", "Кол-во, шт"), даты то нормальные, то текстом, цены вида "54 990 р.", лишние пробелы, дубли и строка "Итого" внизу. Руками сводить это долго, и легко ошибиться.

## Что делает

- находит строку с заголовками в каждом файле, даже если сверху шапка отчета
- приводит названия колонок к одному виду
- разбирает даты в разных форматах (05.03.2026, 2026-03-05 и т.д.)
- чистит числа от пробелов и "р.", убирает лишние пробелы в названиях
- удаляет пустые строки, строки "Итого" и дубли
- добавляет колонку "Филиал" (берется из имени файла) и "Сумма"
- сохраняет `report.xlsx`:
  - лист **Сводная** - выручка по филиалам по месяцам + итоги и график
  - лист **Данные** - все очищенные строки одной таблицей

## Установка

Нужен Python 3.10+

```
pip install -r requirements.txt
```

## Запуск

Положить отчеты в папку `input` и запустить:

```
python merge_reports.py
```

Другие папка и имя итогового файла:

```
python merge_reports.py --input D:\отчеты\март --output март_итог.xlsx
```

В консоли будет видно, сколько строк прочитано из каждого файла и сколько убрано при очистке.

## Тестовые данные

В `input` уже лежат 4 тестовых отчета с типичным "мусором". Сгенерировать их заново:

```
python make_sample_data.py
```

## Если нужно под свои файлы

Названия колонок задаются в словаре `COLUMNS` в начале `merge_reports.py` - туда можно добавить свои варианты ("Кол.", "Стоимость" и т.п.). Форматы дат - в `DATE_FORMATS`.
